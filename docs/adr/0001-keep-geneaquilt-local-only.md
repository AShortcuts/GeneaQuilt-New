# Keep GeneaQuilt permanently local-only

GeneaQuilt will not depend on server-side storage, processing, accounts, hosted sharing, or synchronization. Genealogy Documents remain on the user's device, and any import, export, or sharing action must be explicitly initiated locally by the user. This deliberately gives up automatic cross-device access and collaboration in exchange for a durable privacy promise and a product that never requires users to surrender family data to a GeneaQuilt server.
